# 關卡配置規格書 — 屍體技能卡系統

> 給新進人員 / AI 的快速上手文件。看完這份就能排關卡、調數值、加技能、設陷阱。

## 1. 玩法核心循環

「先抽卡 → 再玩」:

1. 每條命開始,跳出技能卡選擇畫面(遊戲暫停)。玩家從抽到的卡中選一張。
2. 這張卡決定「這條命結束時留下的屍體 / 殘影會是什麼技能」。
3. 玩家帶著已知技能跑動,在想要的位置死亡(自殺 K / 計時歸零)。
4. 屍體在死亡位置生成並帶上該技能,永久留在場上,累積成解謎工具。
5. 回重生點,進入下一條命,再抽卡 → 再玩。

死亡分兩種:

- **自身機制死亡**(按 K 自殺 / 輪迴計時歸零):合法,正常產生帶技能的屍體。
- **非自身機制死亡**(碰到傷害區 `Hazard`):宣告失敗,顯示 `FAILED` 文字後整關重來。

## 2. 系統組成(程式不用改,只設定)

| 元件 | 角色 | 掛在哪 |
|---|---|---|
| `CorpseSkillSystem` | 技能卡系統(抽卡 / 選卡 UI / 把技能附到屍體)。可重用、與管理器解耦。 | 關卡的 GameManager 物件 |
| `LoopManager` | 按鈕輪迴關卡管理器(計時 + 殘影 + 按鈕開門)。**game0 / game1 用這個** | 關卡的 GameManager 物件 |
| `DeadBodyManager` | 屍體墊步關卡管理器(K 自殺疊屍體 + 鑰匙 + 大門) | 關卡的 GameManager 物件 |
| `CorpseSkill_Speed / _Mover / _TeleportDown` | 技能行為元件,死亡時由系統**自動掛到屍體上**,不用手動加 | 屍體(執行時自動) |
| `Hazard` | 傷害區域,碰到即失敗 | 尖刺 / 岩漿等危險物件 |
| `ILevelFailHandler` | 失敗介面,`LoopManager` / `DeadBodyManager` 都實作。`Hazard` 只透過它通知,不綁特定管理器 | (介面) |

一個關卡只會用 `LoopManager` 或 `DeadBodyManager` 其中一種,搭配一個 `CorpseSkillSystem`。

## 3. 技能種類

| 列舉值 | enum index | 顯示名 | 行為 | 屍體顏色欄位 |
|---|---|---|---|---|
| `Normal` | 0 | 普通 | 一般可踩平台,無特殊行為 | `colorNormal` |
| `Speed` | 1 | 加速 | 碰撞器接觸該屍體時速度倍增(X=水平移動、Y=跳躍),離開後隨時間遞減回原速。屍體仍是平台 | `colorSpeed` |
| `HorizontalSway` | 2 | 左右橫擺 | 屍體沿水平來回移動,碰障礙物提前折返,會帶著站在上面的玩家走 | `colorHorizontal` |
| `VerticalSway` | 3 | 上下搖擺 | 同上,改垂直方向 | `colorVertical` |
| `TeleportDown` | 4 | 向下傳送 | **穿透式傳送門**(非平台):玩家經過時被傳送到正下方第一個平台上 | `colorTeleport` |

> 注意:`TeleportDown` 屍體會被設成 Trigger 且移出 Ground 層,所以**不能當平台踩**,只能當傳送門用。

## 4. 卡牌規則(抽卡邏輯)

- **總卡牌(deck)**:每關自訂一副牌,每筆 = 技能種類 + 數量(count)。
- **數量(count)= 抽牌權重**:數量越大,該技能越容易被抽到。同種類多筆會自動合併權重。
- **顯示張數(displayCount)**:每次抽幾張供玩家選。3 = 三選一。
- **無限抽、不消耗**:牌庫永遠不會變少,玩家可以一直死、一直抽。
- 一手牌內**不重複種類**;若牌庫種類數少於 displayCount,就自動變二選一、一選一。
- **牌庫留空 = 停用技能系統**,該關維持原本無技能玩法(屍體一律普通、不跳選卡)。

## 5. CorpseSkillSystem 欄位參考

| 欄位 | 型別 | 預設 | 說明 |
|---|---|---|---|
| `deck` | List | 空 | 總卡牌。每筆設 `type`(技能)+ `count`(數量/權重) |
| `displayCount` | int (≥1) | 3 | 每次抽出幾張(三選一 = 3) |
| `speedMultiplier` | Vector2 | (2, 2) | 加速倍率。**X = 水平移動速度**、**Y = 跳躍力** |
| `speedDecayPerSecond` | float | 2 | 加速離開後每秒遞減的倍率量(2 ≈ 0.5 秒回到原速;設 0 = 永不遞減) |
| `moverDistance` | float | 3 | 移動屍體(橫擺/搖擺)的單程距離 |
| `moverSpeed` | float | 2 | 移動屍體的速度 |
| `groundLayer` | int | -1 | 平台圖層。-1 = 自動抓 `Ground` 層(移動折返、向下傳送、加速偵測用) |
| `colorNormal / colorSpeed / colorHorizontal / colorVertical / colorTeleport` | Color | 各有預設 | 各技能屍體顏色(會保留原本透明度) |

### 數值速查
- 只想加速跑步 → `speedMultiplier = (2, 1)`
- 只想加速跳躍 → `speedMultiplier = (1, 2)`
- 兩者都加速 → `speedMultiplier = (2, 2)`,想更猛 → `(3, 2)`
- 加速想維持久一點 → 把 `speedDecayPerSecond` 調小(如 1);想瞬間消失 → 調大(如 5)

## 6. 管理器欄位(每關必設)

### LoopManager(按鈕輪迴關卡,如 game0 / game1)
| 欄位 | 說明 |
|---|---|
| `spawnPoint` | 玩家重生點 Transform |
| `buttons` | 這關的 `PressButton` 陣列;全部被壓下才開門 |
| `skillSystem` | 技能系統參考(留空會自動抓同物件或場景中的 `CorpseSkillSystem`) |
| `loopTime` | 每輪秒數,時間到自動留殘影重生 |
| `ghostSprite / ghostColor / ghostScale / ghostColliderSize / ghostFlipY / ghostLayer / ghostSortingOrder` | 殘影外觀與碰撞設定(`ghostLayer` 應為 Ground) |
| `failDisplayTime` | 失敗文字顯示秒數(預設 1.5),之後整關重來 |

### DeadBodyManager(屍體墊步關卡)
| 欄位 | 說明 |
|---|---|
| `spawnPoint` | 玩家重生點 Transform |
| `keyObject` | 鑰匙物件(重置時重新啟用) |
| `skillSystem` | 技能系統參考(留空自動尋找) |
| `corpseSprite / corpseColor / corpseScale / corpseLayer / corpseSortingOrder` | 屍體外觀(`corpseLayer` 應為 Ground) |
| `failDisplayTime` | 失敗文字顯示秒數,之後整關重來 |

## 7. 排一個新關卡的步驟

1. 用既有關卡為範本(複製場景或 prefab),或新建。
2. 確認有 **Player**(掛 `PlayerController2D`,Tag = `Player`)、地面/牆在 **`Ground` 層**、重生點 Transform。
3. 在 **GameManager 物件**上:
   - 掛對應管理器(`LoopManager` 或 `DeadBodyManager`)並設好上面的欄位。
   - 掛 `CorpseSkillSystem`,設定 `deck`(技能 + 數量)與 `displayCount`,需要時調 `speedMultiplier`、`moverDistance/Speed`。
4. 要傷害區就在尖刺 / 岩漿那類物件掛 `Hazard`(會自動設成 Trigger)。
5. 通關條件:
   - LoopManager → 擺好 `PressButton` 們 + 門(`LoopDoorExit`),全部按鈕被壓下開門。
   - DeadBodyManager → 擺好鑰匙(`KeyPickup`)+ 大門(`DoorExit`)。
6. 圖層複查:所有「可踩平台」要在 `Ground` 層;玩家 `groundLayer` 要包含 `Ground`。

---

## 8. 測試方式

- 直接 Play 該關場景:
  1. 一進場應暫停並跳出選卡畫面 → 點卡片或按數字鍵 `1/2/3`。
  2. 選完恢復,`A/D` 移動、`W` 跳、`K` 自殺(LoopManager 也可等計時歸零)。
  3. 死亡後該位置出現對應顏色 / 行為的屍體,然後再跳選卡。
  4. 逐一驗證:加速(踩上去變快、離開遞減)、橫擺 / 搖擺(來回移動、撞牆折返、帶玩家走)、向下傳送(走進去被往下送)。
  5. 測失敗:碰 `Hazard` → 出現 `FAILED`,約 1.5 秒後整關重來。
  6. `R` 任意時候重置整關。

---

## 9. 重要注意事項 / 常見坑

- **兩份 Game0**:`Assets/Scenes/Game0.unity` 是可直接 Play 的場景;`Assets/Prefabs/Levels/Level_gameX.prefab` 才是正式流程(選關 → GameScene 載入)用的。若要在正式流程生效,要對 **prefab 內的 GameManager** 做同樣設定。
- **向下傳送不是平台**:它是穿透式傳送門,別拿它當墊腳石。
- **移動屍體目前只帶動玩家**,疊在它上面的其他屍體不會跟著走。
- **`Ground` 層很關鍵**:平台沒在 Ground 層 → 玩家踩不到、移動折返 / 向下傳送 / 加速偵測都會失準。
- **Unity 場景 / prefab 的 Git merge 很容易壞**(衝突標記被當文字 commit 進去會打不開)。建議同一個場景同時間只一人改,或設 `.gitattributes` 的 merge 策略。
